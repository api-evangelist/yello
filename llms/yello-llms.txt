# Yello

> Yello is a Chicago-based talent acquisition software company founded in 2008 (originally Recsolu).
> Its enterprise platform runs campus and early-career recruiting - campus planning, recruitment
> events, sourcing, interview scheduling, a recruitment CRM, analytics and an AI campus recruiting
> agent - for roughly 100 Fortune 500 employers across 70+ countries and 15+ languages. Yello also
> operates Yello Government Recruiting Solutions (YGRS) for public-sector hiring, the WayUp
> early-career candidate marketplace, and Symba new-hire readiness.

This file is GENERATED by API Evangelist from the public Yello surface. Yello does not publish an

## Machine surfaces

- [WayUp MCP server](https://www.wayup.com/mcp) — remote Model Context Protocol endpoint (JSON-RPC 2.0 over streamable HTTP). OAuth-gated: unauthenticated calls return 401 with an RFC 9728 Bearer challenge. Undocumented by the provider.
- [OAuth authorization-server metadata](https://www.wayup.com/.well-known/oauth-authorization-server) — RFC 8414; authorization_code + refresh_token, PKCE S256, dynamic client registration.
- [OAuth protected-resource metadata](https://www.wayup.com/.well-known/oauth-protected-resource) — RFC 9728; resource `https://www.wayup.com/mcp`, scope `mcp`.
- [Status page API](https://yello.statuspage.io/api/v2/components.json) — Atlassian Statuspage; component and incident JSON, plus Atom/RSS history feeds.

## No public API contract

Yello Enterprise is delivered as per-customer tenant sites ending in `yello.co` or `recsolu.com`
(US `us-east-1` and EU `eu-west-1` environments); YGRS sites use neither domain. Yello markets ATS
and HRIS integrations (Workday, Taleo, Oracle Recruiting Cloud, iCIMS, SAP SuccessFactors,
Greenhouse, ADP), but publishes no developer portal, no API reference and no OpenAPI. There is no
`developers.yello.co`, `docs.yello.co` or `api.yello.co` (all NXDOMAIN as of 2026-09-04), and
`yello.co/openapi.json`, `/swagger.json`, `/api-docs` and `/graphql` all return 404. Integration
partners are routed to a contact form.
